# PMP Тренажёр — контекст проекта

## Что это
Веб-тренажёр вопросов в формате экзамена PMI/PMP: подготовка к сертификации и к собеседованиям на позицию руководителя проектов. Вход через Google, у каждого пользователя личный профиль с результатами.

- **Владелец:** Абдулло Абдувохидов (проектный менеджер, IT Park, Ташкент). Не разработчик: ему нужен готовый, проверенный и задеплоенный результат, а не код для самостоятельной сборки. Общение на русском.
- **Сайт (prod):** https://pmp-trainer-xi.vercel.app (адрес `pmp-trainer.vercel.app` принадлежит другому человеку)
- **Репозиторий:** https://github.com/abduvohidov/pmp-trainer, ветка `main`. Каждый push в `main` автоматически деплоится на Vercel (проект `pmp-trainer`, команда abduvohidovs-projects).
- **Версия в Claude (артефакт):** https://claude.ai/artifact/3VFYA8meFz7eNu8h52Ke2m — собирается из `dist-single/index.html` и обновляется публикацией по тому же URL.
- **Бизнес-задача (документ):** https://claude.ai/code/artifact/25c93ba7-5cd9-4d42-91b0-faadab9dbaa8

## Стек
React 19 + Vite + TypeScript + Tailwind v4. Сервера нет. Хранилище подключается через интерфейс `Backend` (`src/storage/`), выбирается автоматически:
- `firebase` — Google-вход + Firestore (на Vercel; конфиг из env `VITE_FIREBASE_*`);
- `claude` — внутри артефакта claude.ai (возможности `db` + `user` + `downloads`);
- `local` — localStorage (локальный запуск без конфига, вход по имени).

**Firebase:** проект `pmp-trainer-5bdbb`, бесплатный тариф Spark. Коллекции: `users/{uid}` (прогресс, JSON), `bank/questions` (запись только admin), `leaderboard/{uid}` (рейтинг недели). Правила лежат в `firestore.rules` и опубликованы в консоли. Admin: `abduvohidov.abdullokh@gmail.com` (env `VITE_ADMIN_EMAILS`).

## Структура
- `src/data/questions.json` — банк вопросов (сейчас 90 из 10 наборов). Поля: `id`, `domain` (people/process/business), `tags`, `source` («Набор N»), `stem`, `options[{label,text,correct}]`, `explanation`, `whyWrong[]` (почему неверен каждый вариант), `en{…}` (английский перевод), `image`, `needsReview`.
- `tools/parse_docx.py` — импорт .docx: правильный ответ определяется по **жёлтой подсветке**.
- `src/logic/engine.ts` — сессии, интервальное повторение (Leitner 1/3/7/14/30 дней), аналитика, полный экзамен (180 вопросов / 230 мин / 2 перерыва, при меньшем банке масштабируется), темп `PACE_MS` ≈ 77 с, рейтинг недели (10 очков за верный ответ + 1 за любой), серия дней.
- `src/pages/` — `Login` (приветственная страница), `Dashboard` (главная, режимы, рекомендация), `Runner` (прохождение), `Result`, `Profile` (в стиле Telegram: шапка, строки, каждый раздел открывается отдельной страницей).
- `src/i18n.ts` — тексты RU/EN, `src/glossary.ts` — подсказки по терминам (EVM, SPI, SME, WBS…).
- `e2e/smoke.mjs` — сквозной тест на Playwright.

## Как работать
1. Сборка: `npm run build` (проверка типов + сборка в `dist`), `npm run build:single` (один HTML для артефакта в `dist-single`).
2. Тест: `python3 -m http.server 4173 --directory dist-single` в фоне, затем `CHROMIUM_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome node e2e/smoke.mjs http://localhost:4173/ [папка_скриншотов]`. Ошибки `ERR_TUNNEL_CONNECTION_FAILED` безвредны: это Google Fonts в песочнице.
3. Перед отправкой посмотреть скриншоты: десктоп 1100–1200 px и телефон 390 px.
4. `git push origin main` (Vercel деплоит сам), затем опубликовать `dist-single/index.html` в артефакт по URL выше.
5. Отчитываться пользователю коротко, по-русски и без технических подробностей.

## Правила UI (по замечаниям владельца)
- Никаких `alert` / `confirm` / `prompt` (во встроенной странице они заблокированы), только компонент `Modal`.
- Шапка: логотип, EN и аватар (аватар ведёт в профиль). Вкладок навигации, админки и отдельной «Статистики» нет: всё смотрится через профиль.
- Карточка вопроса фиксированного размера: длинный текст прокручивается внутри или открывается кнопкой «Читать полностью».
- После ответа бейдж «✓ Верно / ✗ Неверно ⓘ» стоит в строке выбранного варианта; на правильном варианте — «Правильный ответ ⓘ». По клику открывается разбор.
- Сегменты прогресса над карточкой кликабельные.
- Динамические классы Tailwind (`bg-${x}`) не генерируются, нужны явные карты классов.
- React-хуки только до ранних `return` (однажды это ломало вход).
